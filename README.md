# RV NetShare

基于 **Tauri 2 + Vue 3 + Rust** 的局域网文件分享工具，把本机文件/文件夹生成局域网下载链接，其他人用浏览器即可下载。

## 功能

- 选择文件 / 文件夹、粘贴路径、拖拽文件与文件夹创建分享
- 多个分享同时在线，随时停止单个或全部
- 分享卡片一键复制链接、浏览器预览、定位文件
- 局域网网页端自动展示所有分享，文件夹支持逐级浏览
- 独立站点页：添加包含 `index.html` 的文件夹，以静态网页方式在局域网浏览器中打开
- 下载记录按对端 IP 分组，支持单条删除和清空
- 断点续传：HTTP Range / 206 Partial Content，配合下载工具可分段并行下载
- 所有数据只保存在本机：分享列表、下载记录、设置

## 系统要求

- Windows 10 / 11（x64）
- 同一局域网内的设备可通过浏览器访问

## 安装

下载安装包后直接安装：

- NSIS 安装引导程序：`RV NetShare_0.1.0_x64-setup.exe`
- MSI 安装包：`RV NetShare_0.1.0_x64_en-US.msi`

安装后首次启动会自动生成分享服务地址，默认监听 `0.0.0.0:48721`。设置页可自定义
分享端口和站点起始端口；自定义端口被占用时会提示无法使用。

## 使用

1. 启动应用，点击「选择文件」或「选择文件夹」。
2. 系统立刻生成形如 `http://192.168.x.x:48721/s/<id>` 的链接。
3. 把链接发给同一局域网内的人，对方在浏览器打开即可下载或浏览文件夹。
4. 支持多个分享并存；拖拽可一次性混合添加文件和文件夹。
5. 想停用某个分享，点击分享卡片右侧的删除按钮即可。

在「站点」页添加包含 `index.html` 的文件夹后，会为站点分配独立端口并生成形如
`http://192.168.x.x:48800/` 的网址，浏览器直接以静态网页方式打开，
站内 CSS、JS、图片等资源均可正常加载，支持以 `/` 为根路径构建的前端产物。

## 数据存储

- 默认目录：`%LOCALAPPDATA%\rv-netshare\`
- `shares.json`：分享列表，重启后自动恢复，旧链接继续有效
- `sites.json`：站点列表，重启后自动恢复
- `history.json`：下载记录，每次下载自动追加
- `config.json`：配置（自定义保存目录等）
- 设置页可修改保存目录，只影响下载记录存放位置

## 技术栈

- 前端：Vue 3 + TypeScript + Vite + Tailwind CSS v4
- 桌面端：Tauri 2（Rust）
- 内嵌 HTTP/1.1 服务器：`std::net::TcpListener`，线程池逐连接处理，流式分块发送，支持 Range 断点续传

## 开发

```bash
npm install
npx tauri dev
```

## 打包

```bash
npx tauri build
```

输出位置：

- `src-tauri/target/release/bundle/nsis/RV NetShare_0.1.0_x64-setup.exe`
- `src-tauri/target/release/bundle/msi/RV NetShare_0.1.0_x64_en-US.msi`

> MSI 打包需要 Windows Installer 服务可用；首次构建 NSIS 需要联网下载工具链。

## 说明

- 同一个系统对话框不能同时勾选文件和文件夹，可先选文件再选文件夹，或直接拖拽混合添加。
- 局域网网页端支持深色模式，跟随系统外观。
- 应用使用自定义无边框标题栏，按住顶部空白区域可拖动窗口。
