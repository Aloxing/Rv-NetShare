# RV NetShare

基于 **Tauri 2 + Vue 3 + Rust** 的局域网文件分享工具，把本机文件/文件夹生成局域网下载链接，其他人用浏览器即可下载。

## 功能

- 选择文件 / 文件夹、粘贴路径、拖拽文件与文件夹创建分享
- 多个分享同时在线，随时停止单个或全部
- 分享卡片一键复制链接、浏览器预览、二维码扫描、定位文件
- 局域网网页端自动展示所有分享，文件夹支持逐级浏览
- 独立站点页：添加包含 `index.html` 的文件夹，以静态网页方式在局域网浏览器中打开，支持以 `/` 为根路径构建的前端产物
- 下载记录按对端 IP 分组，支持单条删除和清空
- 断点续传：HTTP Range / 206 Partial Content，配合下载工具可分段并行下载
- 设置页可自定义分享端口和站点起始端口
- ngrok 内网穿透：在设置页填写 ngrok Authtoken 后，可分别为单个分享或站点开启公网隧道，生成可访问的公网链接
- 所有数据只保存在本机：分享列表、站点列表、下载记录、设置
